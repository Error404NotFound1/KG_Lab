\section{绪论}
\subsection{项目背景、发展现状及意义和目标的理解}
变构飞行器是航空航天领域的重要研究方向，其核心特征在于飞行器能够根据任务需求与飞行环境主动调整外形、结构或翼面参数，从而在巡航、机动、跨域飞行等不同阶段获得更优的气动性能和控制性能。与传统固定构型飞行器相比，变构飞行器具有更强的任务适应能力和多学科耦合特征，其研究涉及气动设计、结构设计、变形机制、飞行控制、性能评估和任务规划等多个层面。

从学科发展现状看，变构飞行器相关研究已逐步从单一构型创新走向“结构—控制—任务”一体化协同优化。随着智能控制、先进材料、柔性机构和多源感知技术的发展，变构飞行器研究对象不再局限于某一机翼变形形式，而是扩展到可伸缩翼、可折叠翼、可变后掠翼、仿生扑翼与跨介质构型等多种类型。由此带来的一个直接问题是：领域知识规模快速增长，但知识载体高度分散，不同文献中的术语表达、结构划分方式和关系描述口径并不统一，研究者在查找和复用知识时往往需要投入大量人工阅读与归纳成本。

当前该领域知识主要分散在论文、专著、综述和技术文档中，存在术语表达不统一、知识关系隐含、资料分散且难以直接进行语义检索的问题。传统关键词检索只能解决“找到文献”的问题，难以支持“某类飞行器采用哪些控制方法”“哪些参数会影响某种性能指标”“某部件属于哪种结构体系”这类关联性问题。知识图谱通过将实体、关系与证据句组织为结构化网络，能够有效支撑领域知识组织、语义检索、关系探索和可视化分析，因此在变构飞行器领域具有较强应用价值。

进一步看，航空航天类专业文献的知识表达具有明显的隐式性和交叉性。同一个概念在不同文献中可能出现不同翻译、不同缩写或不同命名粒度；同一种控制方法也可能通过“采用”“基于”“结合”“引入”等多种句式表达；某些结构关系并不以显式模式出现，而是分散在长句、并列句甚至跨句语境中。这使得单纯依赖人工词表或简单匹配策略很难获得稳定结果，也使得完全依赖黑盒模型在课程项目环境中缺少足够可解释性。因此，构建一套面向专业文献、兼顾召回率、精度和工程可维护性的知识获取方案，具有较强现实意义。

本项目面向变构飞行器文献语料，设计并实现了一套从 PDF 文本获取、术语构建、实体关系抽取、图谱导出到前端可视化展示与算法评估的完整流程。项目目标包括：构建面向该领域的术语体系与实体类型体系；形成稳定的实体识别与关系抽取方法；建立支持 JSON、CSV、TTL 导出的知识图谱数据；开发可交互的图谱展示系统；利用人工金标准对算法效果进行定量评估。通过该项目，希望实现一套兼顾完整性、规范性与工程可落地性的课程级知识图谱原型系统。

从课程项目价值看，本项目不仅关注“能否抽出一些三元组”，更关注是否形成了从知识源整理、算法实现、结果评估到系统展示的闭环。也就是说，项目最终目标并不是得到孤立的实验数值，而是构建一个可以被展示、被解释、被复现的领域知识组织原型。对于知识图谱课程大作业而言，这种完整闭环比单点算法演示更能体现系统性，也更符合工程实践导向。

\subsection{项目实施技术路线及方案}
本项目总体采用“文献输入—文本预处理—术语构建—知识抽取—图谱导出—系统展示—算法评估”的技术路线。系统以 Python 为核心开发语言，后端基于 FastAPI，前端基于 ECharts，文本处理与统计建模结合 PyMuPDF、pdfminer.six、jieba、pandas 等工具库，并在术语定稿阶段引入 OpenAI 兼容大模型接口。

与单一深度学习方案不同，本项目采用了双模混合智能（Hybrid）架构，即“统计方法 + 规则系统 + LLM 抽取与精筛”。在工程实现上，系统支持检测人工金标词典：当存在人工词典时，维持高标准、高可解释性的规则引擎；否则自动切换为全自动大语言模型模式，以此保证系统的学术可复现性与工程泛化性。此外，大语言模型不仅用于术语归一化和类型定稿，还被深度整合到上下文感知的关系抽取中，并辅以多线程并行调度（ThreadPoolExecutor）以突破调用瓶颈，这既避免了纯规则方法产生的图谱稀疏问题，又显著提升了大规模数据处理的并发效率。
